# Build and acceptance state — v0.2.1

RIGHTCLICK v0.2.1 is based on current main plus the bounded onboarding and profile-integrity hardening that was independently accepted before release preparation.

The final integrated live acceptance executed 219 tests with 0 skipped and 0 failures. The eight environment-backed tests all ran for real: Bonjour lifecycle discovery/removal/replacement, specification and invocation origin-authority redirects, the 1 MiB OpenAPI acquisition boundary, the five-second acquisition deadline, and a real localhost OpenAPI provider. The seven generic bearer-authority tests also passed.

The real Bonjour lifecycle additionally passed three consecutive control runs. Provider replacement produced a new capability identity; both live executions were independently verified and stale identities became unavailable. Cross-origin redirect testing recorded zero forbidden sink requests.

The v0.2.1 production code preserves the current-main OpenAPI/Core/MCP surfaces, including structured JSON operations, GET path arguments and origin-bound bearer authority. The onboarding integration adds stable Homebrew entrypoint handling, transactional ChatGPT setup, live process attestation, profile-integrity enforcement and Homebrew-upgrade state reconciliation.

The primary distribution path is Homebrew on Apple Silicon/macOS 14+. The deterministic source package is generated by python3 scripts/package-source.py; it contains pinned build inputs, tests, fixtures and dependency notices while excluding Git metadata, build caches, personal configuration and raw execution evidence. Source fallback requires Swift 6.2+ from the free Apple Command Line Tools.

Pre-publication acceptance does not by itself prove the public release asset or public Homebrew install. The release procedure therefore requires exact public-byte verification and fresh Homebrew acceptance after publication.

Historical v0.1 and v0.2.0 evidence remains preserved as historical evidence and is not rewritten to describe v0.2.1.
